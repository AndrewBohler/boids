# boids
Boid simulation using Python and pygame.

## Setup

Requires [uv](https://docs.astral.sh/uv/).

```
git clone https://github.com/AndrewBohler/boids
cd boids
uv run main.py
```

`uv` will handle creating the virtual environment and installing dependencies (`numpy`, `pygame-ce`) automatically.
